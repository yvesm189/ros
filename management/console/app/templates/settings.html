Enrollment

A workstation joins this console by presenting the enrollment key once. It receives its own token in return and never uses the key again.

{{ enrollment_key }}

sudo ros-agent enroll --server {{ server_url }} --key {{ enrollment_key }}

Or write it into /etc/ros/agent.conf on the image, so machines enroll on first boot.

Administrator access

The console password comes from the ROS_ADMIN_PASSWORD environment variable. Change it in management/docker-compose.yml or the service environment and restart.
